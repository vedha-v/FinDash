# FinDash - Project Statement

## Problem Statement

Managing personal finances manually can make it difficult to keep track of income, expenses, spending limits and overall financial patterns. Users may record transactions in different places or rely on manual calculations, making it harder to understand where their money is being spent.

FinDash addresses this problem by providing a centralized desktop application for recording financial transactions, managing category-based budgets, calculating financial summaries and visualizing spending patterns.

## Proposed Solution

FinDash is a Java-based personal finance dashboard that provides a single interface for managing personal financial information.

The system allows users to:

- Record income and expenses
- Modify and delete transactions
- Search and filter transaction records
- Create and manage category-based budgets
- Track spending against budgets
- Calculate income, expenses and balance
- Analyze spending by category
- Visualize category spending using a bar chart

The application uses JavaFX for the graphical interface and SQLite with JDBC for persistent local storage.

## Expected Outcome

The completed system provides users with a simple interface for recording and analyzing personal financial information while demonstrating Java programming concepts including object-oriented programming, collections, exception handling, database connectivity and GUI development.
